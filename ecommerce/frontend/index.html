Offline Model Evaluation & Holdout Validation

Quantitative validation metrics evaluated using an 80/20 train/test holdout basket split (Admin Access).

Hit Rate @ Top 5 Recommendations

--

In holdout customer baskets, percentage where model's top 5 predictions anticipated co-purchased items.

Mean Precision @ Top 5

--

Average ratio of recommended items that matched actual ground truth co-purchased items in test transactions.

Catalog Coverage

--

Percentage of total catalog items actively connected into statistical co-purchase rule networks.

Average Rule Lift Ratio

--

Co-occurrence probability compared to independent random chance across mined association patterns.

Holdout Validation Methodology

  • Dataset Split: 18,266 transaction baskets split into 14,612 Train Baskets (80%) and 3,654 Test Baskets (20%).
  • Simulation Protocol: For each test basket (size ≥ 2), 1 item is masked as user input query while remaining items serve as hidden ground truth.
  • Strict Separation: Rules mined strictly on training split to prevent data leakage.
  • Multi-Tier Strategy: Graceful fallback to item co-occurrence similarity when rules are exhausted.
