Holdout Validation Methodology

  • Dataset Split: 18,266 transaction baskets split into 14,612 Train Baskets (80%) and 3,654 Test Baskets (20%).
  • Simulation Protocol: For each test basket (size ≥ 2), 1 item is masked as user input query while remaining basket items serve as hidden ground truth.
  • Strict Separation: Association rules mined strictly on training transactions to prevent data leakage.
  • Cold-start Strategy: Graceful fallback to global top-frequency items when no rule matches novel item combinations.
